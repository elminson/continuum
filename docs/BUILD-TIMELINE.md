# Build timeline

Most of Continuum was built before the hackathon weekend (14–15 November 2026). We say so plainly here, so judges can tell what came before and what we did during the event. The full history is public: https://github.com/elminson/continuum/commits/main

## Before the event (29 September – 13 November 2026)

- **29–30 September.** First commit, with the app's core: FIRMS ingestion, the 1 km cell-day grid, the two transfer functions with held-out validation, the calendar, unusual-period alerts with maps, the How it works page, the public API and the alert analyst on self-hosted Ollama.
- **12 November.** Spanish interface, faster dashboard queries, a backfill fix.
- **13 November.** Final preparation:
  - moved off the retired Suomi NPP near-real-time feeds;
  - made the scheduled harmonize lighter and moved aggregation into Postgres;
  - removed the self-hosting block from the API page;
  - added the shared judge account;
  - fixed the alert map width.

## During the event (14–15 November 2026)

- Chose the four public areas (Hispaniola, Cuba, Gran Chaco, Cerrado) and checked their live validation numbers.
- Checked the Cuba alert of 17 August 2026 against wildfire reports from the same days.
- Wrote the submission text and updated the README.
- Made the 7-slide presentation in English and Spanish.
- Made the 30-second demo videos in English and Spanish (Spanish with English subtitles).
- Wrote the speaker script for the in-person presentation.
- Kept the live site current with hourly NASA FIRMS data.
